# 🎮 GameBot — Telegram-бот з іграми

## 📌 Опис проєкту

**GameBot** — це Telegram-бот, створений на Python за допомогою бібліотеки `python-telegram-bot`. Він дозволяє користувачам грати у вікторини, відгадувати загадки, виконувати випадкові завдання та заробляти бали.

Проєкт демонструє використання асинхронних функцій, обробників команд, кнопок Telegram і роботи з даними користувача.

## ✨ Можливості

- **🎯 Вікторина** — відповіді на запитання з різних тем.
- **🧩 Загадки** — розв'язування загадок із перевіркою відповідей.
- **🎲 Випадкові завдання** — отримання цікавих завдань.
- **🏆 Система балів** — 1 бал за правильну відповідь у вікторині та 2 бали за розгадану загадку.
- **📋 Головне меню** — зручна навігація за допомогою кнопок.
- **ℹ️ Довідка** — список команд та пояснення можливостей бота.
- **⛔ Завершення гри** — можливість зупинити поточну гру командою `/cancel`.

## 🛠️ Використані технології

- Python 3
- `python-telegram-bot`
- Telegram Bot API
- `random` — вибір випадкових завдань і загадок.
- `logging` — ведення журналу подій.

## ⚙️ Встановлення та запуск

### 1. Клонування або завантаження проєкту

Завантаж проєкт на комп'ютер і відкрий його в PyCharm.

### 2. Встановлення бібліотеки

Відкрий термінал у папці проєкту та виконай:


python -m pip install python-telegram-bot


### 3. Створення Telegram-бота

1. Відкрий Telegram.
2. Знайди офіційного бота `@BotFather`.
3. Надішли команду `/newbot`.
4. Вкажи назву та унікальний username.
5. Скопіюй отриманий токен.

### 4. Налаштування токена

Відкрий файл `main.py` і встав свій токен у змінну `TOKEN`:


TOKEN = "ТВІЙ_ТОКЕН"


**Увага:** не публікуй токен у відкритому доступі та не додавай його до публічного репозиторію.

### 5. Запуск бота

Виконай команду:


python main.py


Якщо все налаштовано правильно, у терміналі з'явиться повідомлення:


GameBot запущено!


Після цього відкрий свого бота в Telegram і натисни кнопку **Start**.

## 🤖 Команди бота

| Команда | Призначення |
|---|---|
| `/start` | Запуск бота та відкриття головного меню |
| `/help` | Перегляд довідки |
| `/quiz` | Початок вікторини |
| `/riddle` | Отримання загадки |
| `/task` | Отримання випадкового завдання |
| `/score` | Перегляд набраних балів |
| `/cancel` | Завершення поточної гри |

## 🏆 Система балів

У боті реалізована проста система винагород:

- Правильна відповідь у вікторині — **1 бал**.
- Правильна відповідь на загадку — **2 бали**.

Наразі результати зберігаються в пам'яті під час роботи бота. Після його перезапуску статистика не зберігається.

## 🔒 Безпека

- Не публікуй токен Telegram-бота.
- Не завантажуй конфіденційні дані до відкритого репозиторію.
- Якщо токен став відомий стороннім особам, створи новий через `@BotFather`.
